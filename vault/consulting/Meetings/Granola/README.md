# Granola Meeting Notes

This folder is populated automatically if you use Granola (granola.ai) with the Obsidian sync integration.

**If you're not using Granola:** delete this folder. The vault will work without it — create meeting notes manually using the `Templates/Meeting Note.md` template and store them in `Meetings/Notes/` instead.

**If you add Granola later:** re-create this folder structure with Notes/ and Transcripts/ subfolders, then configure the Granola Obsidian plugin to point at this folder.
